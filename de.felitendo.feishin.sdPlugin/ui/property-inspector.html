How to connect Feishin
  1. Open Feishin on this computer and go to Settings → Window → Remote.
  2. Turn on Enable remote control server.
  3. Set the username to feishin and the password to streamdeck. Already using other credentials? Enter them below instead.
  4. Keep the port at 4333, or enter your port below.

The status at the top turns green as soon as the connection works.

These settings apply to all Feishin actions. Leave a field empty to use the default.
